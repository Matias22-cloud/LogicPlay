Ejercicios Resueltos Paso a Paso

Básico Ejemplo 1: Agua (H₂O)
Masas: H = 1g, O = 16g
Masa Molecular (Total) = (2 × 1g) + (1 × 16g) = 18g/mol
  • Porcentaje de Hidrógeno (H):
    ( (2 × 1g) / 18g ) × 100 11.11%
  • Porcentaje de Oxígeno (O):
    ( (1 × 16g) / 18g ) × 100 88.89%
Doble elemento Ejemplo 2: Dióxido de Carbono (CO₂)
Masas: C = 12g, O = 16g
Masa Molecular = 12g + (2 × 16g) = 44g/mol
  • Carbono (C):
    (12g / 44g) × 100 27.27%
  • Oxígeno (O):
    (32g / 44g) × 100 72.73%
Múltiples Elementos Ejemplo 3: Glucosa (C₆H₁₂O₆)
C = 12g, H = 1g, O = 16g
Masa = (6×12) + (12×1) + (6×16) = 72 + 12 + 96 = 180 g/mol
  • Carbono (C):
    (72g / 180g) × 100 40.00%
  • Hidrógeno (H):
    (12g / 180g) × 100 6.67%
  • Oxígeno (O):
    (96g / 180g) × 100 53.33%
