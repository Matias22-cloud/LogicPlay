Ecuaciones de 2do Grado

Dominando la forma general y sus variantes.

Definición Matemática

Una ecuación cuadrática es aquella donde la variable x tiene como exponente máximo el 2. Su forma estándar es:

a\(x^2\) + bx + c = 0
Constante a

Coeficiente cuadrático. Nunca cero (a ≠ 0). Dicta si la parábola abre arriba o abajo.

Constante b

Coeficiente lineal. Mueve la parábola de forma lateral.

Constante c

Término independiente. Es el punto donde se corta el eje Y.

category Clasificación de Funciones

01. Completas

Tienen los tres términos (a, b y c son diferentes a cero).

3\(x^2\) + 2x - 5 = 0

02. Incompletas

Les falta el término lineal (b=0) o el independiente (c=0).

\(x^2\) - 9 = 0
2\(x^2\) + 4x = 0

03. No Cuadráticas

Si "a" es cero o si el exponente es distinto de 2, ¡no son!

5x + 3 = 0
\(x^3\) + 2\(x^2\) = 0

Reglas Geométricas

¿Cómo identificar el "fraude"?

Si ves una ecuación donde la x está "desnuda" (exponente 1), es una recta. Si tiene un 3, es una cúbica. La cuadrática siempre tiene un 2 como líder.

El poder de "a"

Si a es positivo, la parábola sonríe. Si a es negativo, está triste. ¡Sin "a" no hay parábola!

warning

"Mucho cuidado: Una ecuación incompleta sigue siendo cuadrática, pero una sin \(x^2\) es solo una línea."
