1. Factor Común

Factorizar por factor común es como buscar un ingrediente que se repite en todos los platos. Si todos los términos tienen la misma letra o se pueden dividir por el mismo número, sacamos ese elemento fuera de un paréntesis.

Explicación del Ejemplo

Ecuación: 6x² + 12x = 0

  • Paso A: Buscamos el número más grande que divida a 6 y 12. Es el 6.
  • Paso B: Vemos qué letra se repite. Ambos tienen "x", elegimos la de menor exponente: x.
  • Paso C: Dividimos cada término original entre 6x. Nos queda: 6x(x + 2) = 0.
  • Paso D: Para que la multiplicación dé cero, o 6x es 0, o (x+2) es 0.
  • Raíces: x₁ = 0, x₂ = -2

2. Trinomio Simple (x² + bx + c)

Este método se usa cuando la x² está sola (sin número al lado). La meta es encontrar dos números mágicos. Estos dos números, al sumarse, deben dar el número del medio, y al multiplicarse, deben dar el número del final.

Explicación del Ejemplo

Ecuación: x² + 5x + 6 = 0

  • Paso A: Buscamos números que multiplicados den 6 (pueden ser 6x1 o 3x2).
  • Paso B: De esos pares, ¿cuál suma 5? El 3 y 2.
  • Paso C: Escribimos dos paréntesis: (x + 3)(x + 2) = 0.
  • Paso D: Cambiamos el signo de los números para hallar las x.
  • Raíces: x₁ = -3, x₂ = -2

3. Trinomio Compuesto (ax² + bx + c)

Este es para cuando la x² tiene un número acompañándola. El truco es multiplicar el primer número por el último para simplificar el problema y luego repartir el primer número entre los paréntesis.

Explicación del Ejemplo

Ecuación: 2x² + 5x + 3 = 0

  • Paso A: Multiplicamos el primero (2) por el último (3). Nos da 6.
  • Paso B: Buscamos números que sumen 5 y multipliquen 6. Son 3 y 2.
  • Paso C: Montamos la estructura: (2x + 3) y (2x + 2).
  • Paso D: Simplificamos el paréntesis que se pueda: (2x + 3)(x + 1).
  • Raíces: x₁ = -1.5, x₂ = -1
